- **implicit_question**: 공실을 깔고 가는 건물주의 진짜 효용함수는 '임대료 수령'이 아니라 '건물 평가가치 사수' 아닌가? 그렇다면 시세 인하는 임대료 손실이 아니라 자산 디스카운트로 잡혀버리는 것 아닌가?
- **reasoning_move**: 헤드라인=공실=손실=내려야 합리적이라는 1차 해석을 거부. 임대료를 7천으로 내리는 순간 가치=1억/금리에서 7천/금리로 자산이 6억 깎이는 *확정손실*. 3년 공실 = 3억 손실은 6억 자산훼손보다 작음 → '버티기'가 NPV 최적해. 게다가 와이모임으로 쓰겠다며 컨설팅 오는 건물주가 다수라는 점에서 *현금흐름 의존도 자체가 낮은 모집단*까지 추가 변수.
- **matched_thinking_pattern**: 공실 장기화를 '비합리 고집'이 아니라 자본환원율 방어 함수의 합리적 해로 다시 푸는 사고
- `causal_chain`: [수요 위축으로 임대 미달] → [임대료 인하 = 자본환원율 통한 자산가치 확정훼손] → [건물주는 임대료 인하보다 공실 NPV 선호] → [공실이 시세를 떠받쳐 사이클 회복 시 다시 임대 회수]

- **matched_thinking_pattern**: 내국인 유동이 아니라 *공항철도-숙소-스팟 외국인 동선*을 회전율·객단가·아이템 적합도의 1차 변수로 두는 사고
- `causal_chain`: [공항철도 → 홍대 숙소 클러스터] → [외국인 평일 객단가가 카테고리 결정] → [홍대 = 코스메틱, 안국 = 베이커리, 명동 = 잠자기·찍기 만] → [카페는 데이트·체험 수요(한남·도산) 외엔 외국인으로 못 산다]

### E005 공장 잔존가치 자가훼손
- `framework`: **commoditization** · `labels`: startup_business, investment_strategy · `direction`: bearish_long · `horizon`: long
- `speakers`: 유정수 + 안스타 · `grade`: medium (7/10)
- **attention_hook**: 성수가 위기라는데 왜 위기야? 임대료 오른 거 말고 — 건물주들이 황금알 낳는 거위를 직접 가르고 있다는 거잖아. 공장형 창고가 색깔의 본체였는데 그걸 16층으로 갈아엎으면 그게 강남이지 성수냐.
- **implicit_question**: 성수의 '잔존가치=붉은벽돌 공장' 자산이 용적률 400%로 인해 *건물주의 합리적 단기최적화 결정*에 의해 무너진다면, 잔존가치 모델은 사실 자가 침식에 취약한 것 아닌가?
- **reasoning_move**: 1차 해석=성수 임대료 폭등=상권 성숙으로 호재라는 시각 거부. 용적률 400% + 무신사·젠틀몬스터의 건물 매입 → 한층 공장 철거 후 12~16층 신축 → 색깔 사라짐 = '강남 신도시'와 차별점 소실. 즉 잔존가치를 만드는 주체와 파괴하는 주체가 동일인이라는 *내부 모순*을 변수로 추가, 성수의 향후 5년 차별성 소실을 단정.
- **matched_thinking_pattern**: 상권의 차별화 자산을 *임대 수익 극대화*를 위해 본인이 직접 파괴하면서 결국 강남화·획일화로 떨어지는 자기파괴 동학을 읽는 사고
- `causal_chain`: [공장형 창고 = 성수 잔존가치] → [용적률 400% + 임대료 폭등이 신축 인센티브] → [건물주가 잔존가치 자가파괴] → [성수의 차별성 소실 = 강남화]

### E006 카페 트렌드 공간 → 맛 전환
- `framework`: **platform_shift** · `labels`: startup_business, consumer_electronics, brand_strategy · `direction`: bearish_long · `horizon`: mid
- `speakers`: 안스타 + 유정수 + 이재용 · `grade`: high (8/10)
- **attention_hook**: 근교 1500평 카페 한 달 매출이 1억 5천이래. 평당 10만원도 안 나오는 거잖아. 동양 최대로도 안 되는 시장이 됐는데, 왜 아직도 짓고 있지?
- **implicit_question**: 대형 베이커리 카페가 안 되는 게 단순 공급 과잉이 아니라 *대중의 맛 분별력*이 임계점을 넘어선 platform shift 아닌가? 그렇다면 공간 자본을 쌓던 사업자는 구조적으로 비중축소 대상 아닌가?
- **reasoning_move**: 1차 해석=대형 카페 부진은 경기·공급 과잉 탓이라는 통념 거부. 코로나 전후로 대중이 커피 맛을 *구분 가능*해진 임계점에 도달 → 공간 위주 인스타그램 카페는 멋만으로 못 끌고 맛+가격으로 가야 함. 동시에 B2C 홈브루잉(원두 정기구독, 언스페셜티 같은 몰 매출)이 B2B(카페 창업) 시장 위축을 흡수 → 가치 포획 위치가 *원두로 이동*. 따라서 카페 차리지 마라는 결론, B2C 원두 브랜드와 맛 차별화 카페만 수혜.
- **matched_thinking_pattern**: 고객 가치 포획 지점을 '공간·인스타그래머블'에서 '맛·전문성·B2C 홈브루잉'으로 이동했다고 보고 그 흐름에서 벗어난 비즈니스를 일괄 비중축소로 처리하는 사고
- `causal_chain`: [대중 미각 분별력 임계 도달] → [공간 차별화 효용 체감] → [B2B 카페 창업 위축 + B2C 홈브루잉 확장] → [가치 포획 = 원두·맛 차별화 + 외국인 객단가 매칭 카페만 생존]
