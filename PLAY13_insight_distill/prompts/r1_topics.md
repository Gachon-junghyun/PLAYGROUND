# R1: 토픽 라벨링 (Agent용 프롬프트)

> 이 파일은 격리된 Agent 컨텍스트에 그대로 전달된다. self-contained여야 함.

---

## 너의 역할
한국 경제 유튜브 4채널(김단테 월가아재 / 오선의 미국 증시 라이프 / 머니코믹스 / 머니그라피)에서 추출된 명제 958개에 **토픽 라벨**을 부여하는 분류기.

이 결과물은 다음 단계(R2 카드 합성)의 그룹화 키로 쓰인다. 즉 같은 라벨로 묶인 명제들이 한 장의 "사고회로 카드"로 합성될 것. 그래서 라벨이 너무 잘면 카드가 잘게 쪼개지고, 너무 굵으면 카드 안에 서로 다른 얘기가 섞인다.

## 작업 (2단계)

### Step 1. 토픽 라벨 사전 만들기 (20~30개)
958건을 전체적으로 훑고 라벨 사전을 설계해라.

**라벨 규칙:**
- 영어 snake_case, 1~3단어 (예: `fed_policy`, `semiconductor_cycle`, `oil_geopolitics`)
- **20~30개**가 목표. 25개 근처 권장.
- 4채널 모두 커버해야 함. 한 채널만의 라벨이 너무 많으면 안 됨.
- 다음 4개 영역의 균형을 의식해라:
  - **매크로**: 연준/금리/인플레/고용/유가/환율/지정학
  - **산업·섹터**: 반도체/AI/자동차/에너지/유통/엔터/게임
  - **기업·종목**: 개별 기업·종목 단위 (단 너무 잘게 쪼개지 말 것 — 비슷한 회사는 묶기)
  - **일반론·메타**: 투자 철학/시장 심리/리스크 관리/매크로 vs 종목 선택
- 라벨 사전 자체에 한국어 한 줄 설명 부착 (어떤 명제가 여기 들어가는지).

**Step 1 출력:** `data/r1_topic_dict.md`
```markdown
# R1 토픽 라벨 사전 (총 N개)

## 매크로
- `fed_policy` — 연준 금리 결정, 점도표, FOMC 발언
- `inflation_data` — CPI/PCE 등 인플레 지표
- ...

## 산업·섹터
- `semiconductor_cycle` — 반도체 사이클, 메모리, 파운드리
- ...

## 기업·종목
- ...

## 일반론·메타
- ...
```

### Step 2. 각 명제에 라벨 부여
958건 각각에 **라벨 1~2개** 부여. 어느 라벨에도 안 맞으면 `["noise"]`.

**판단 기준:**
- `proposition`을 주 근거로 보고, `raw_quote`로 보조 확인.
- 한 명제가 분명히 2 토픽에 걸치면 2개 (예: "연준 금리 동결로 반도체 주가 상승" → `fed_policy` + `semiconductor_cycle`).
- 노이즈 판단은 인색하게: 의미가 불분명하거나 비금융·비투자 일반론만 `noise`. 약하게라도 금융 관련이면 가까운 라벨 부여.

**Step 2 출력:** `data/r1_topics.jsonl`
각 줄:
```json
{"id": "<video_id>:<chunk_idx>:<sentence_idx_in_chunk>", "labels": ["fed_policy", "inflation_data"]}
```
id는 위 3필드 조합으로 유일하게 만들어라 (s1_clean.jsonl에 별도 id 필드 없음).

## 최종 보고 (Agent → 메인 컨텍스트)

200단어 이내로 다음만 보고:

1. **라벨 사전 크기**: N개
2. **라벨별 명제 수 top 10** (큰 라벨 위주)
3. **noise 비율**: M/958
4. **라벨링 중 발견한 특이사항** (예: "머니그라피는 brand_strategy / content_creator 라벨이 압도적으로 많아서 다른 3채널과 성격이 다름")
5. **R2(카드 합성) 진입 전 사용자에게 권하는 조정사항** (예: "라벨 X가 200건이라 카드 4~5장으로 분할 필요")

산출물 파일 2개의 절대경로도 같이 보고.

## 하지 마라
- 명제를 요약하거나 변형하지 마라. 라벨링만 한다.
- 라벨 사전을 너무 잘게 쪼개지 마라 (40개 넘으면 안 됨).
- 라벨 사전을 너무 굵게 잡지 마라 (15개 미만이면 안 됨).
- "noise"를 남발하지 마라 — 의심스러우면 가까운 라벨 부여.
- 한국어 라벨 사용 금지 (영어 snake_case만).
