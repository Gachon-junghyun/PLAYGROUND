## ② 질문 기법 (대화를 상대에게 넘기고 깊이를 만드는 질문)

실제 등장한 질문들:
- **상대를 끌어들이는 질문** — "다정피디는 어때요? 평소에 좀 쓰시나요?" (흥버튼). 개념 설명 직후 *상대 경험*으로 턴을 넘김.
- **경험 유도 질문** — "손해를 본 적이 있으세요?" → 운전 일화가 튀어나옴(흥버튼). 추상→구체로 내려가는 장치.
- **되돌려주는 질문(턴테이킹)** — "많이 바쁘신가 봐요, 어떤 걸로 제일 바쁘세요?"(희렌최널이 *권장*한 형태). 내 얘기 대신 상대 죽을 상대에게 고정.
- **자가 점검 질문** — "내가 이 대화에서 남기고 싶은 한 문장이 뭘까?"(희렌최널). 말하기 전 스스로에게.

**관찰:** 좋은 질문은 정보 요청이 아니라 **턴을 넘기는 도구**다. "설명 → 너는 어때? → (상대 경험) → 일반화" 가 반복 리듬.

## ③ 대화 잇기 (threading — 턴이 어떻게 연결됐나)

흥버튼 2인 대담에서 반복된 연결 패턴:

1. **개념 → 자기 고백 → 방법 → 결심** 사이클
   강사 "확신 없는 말투가 손해" → PD "저 원래 엄청 썼어요" (취약점 노출) →
   강사 "결론부터 즉답하세요" → PD "오늘부터 일기 써볼게요" (행동 약속). 한 토픽이 이 4박자로 닫힘.

2. **실시간 따라하기 루프** (발음편)
   "한번 해볼까요?" → PD 시도 → "오 그렇죠 / 더 올려야 돼요" 즉각 피드백 → 재시도.
   가르침을 *대화로* 만든 핵심 장치. 시청자도 같이 따라하게 됨.

3. **맞장구 + 확장** — "맞아요" 로 일단 받고 → 자기 사례를 1개 덧붙여 화제를 굴림.
   (희렌최널이 경고한 "저도 바빠요" 식 *턴 뺏기*와의 차이: 받은 뒤 **상대에게 되돌려준다**.)

**관찰:** 잘 이어지는 대화는 "받기(맞장구) → 보태기(내 사례 1개) → 넘기기(질문)" 3단이 끊기지 않는다. 보태기에서 멈추면 턴 뺏기, 넘기기까지 가야 대화.

## ④ 유머 (어떤 종류였고, 왜 먹혔나)

| 유형 | 사례 | 작동 원리 |
|---|---|---|
| **자기 비하/실패담** | (흥버튼 발음) "저 긴장해서 종이가 젖었어요, 엄지가 땀에" / "염소가 됩니다 메에에" / "랩 같았죠?" | 가르치는 사람이 자기 약점을 먼저 깜 → 권위 낮추고 친근감↑. 실패를 웃음으로 덮어 안전한 연습 분위기 |
| **과장 셀프 칭찬(개그)** | (흥버튼) 설거지하고 "와 씨 장난 아닌데, 눈이 부시네 아주" | 사소+과장의 낙차에서 웃음. *동시에* "나를 과하게 칭찬하라"는 메시지 전달 — 유머가 교훈을 실어 나름 |
| **캐릭터 희화화** | (비치키) "0.7의 남자" — 근거 없는 자신감 캐릭터, "쌉존잘", 반전(다 가고 혼자 취함) | 나쁜 예를 *캐릭터*로 만들어 비웃게 함 → 대비로 좋은 예(센스/타이밍)가 선명해짐 |
| **콜백(callback)** | (흥버튼) 앞에서 "안녕하세요" 발음 틀린 걸 뒤에서 "또 안녕하세요 하고 있네" 로 재소환 | 앞 장면을 뒤에서 다시 꺼내 "우리만의 맥락"을 만듦 → 친밀감 |
| **상황 패러디** | (희렌최널) SK하이닉스 면접 패러디("고성능 SSD 인재", "기억은 선택적 delete") | 극단적 나쁜 예시로 과장 → 내 얘기도 "정도의 차이일 뿐"이라 찔리게 만듦 |

**관찰:** 토크의 유머는 대부분 **"권위 내려놓기(자기 비하)"** 아니면 **"나쁜 예 과장(캐릭터/패러디)"** 두 갈래. 둘 다 *웃기려고만* 있는 게 아니라 교훈을 태워 나르는 운반체다.

## ⑥ Claude 제안 — 토크에서 쓰면 좋을 스킬 (내가 보태는 것)

자막을 보며 "이건 의식적으로 쓰면 좋겠다" 싶은 것들:

1. **"너는 어때?" 핸드오프** — 내 의견 1개 말한 뒤 반드시 상대 경험으로 넘긴다. 독백을 대화로 바꾸는 가장 싼 스위치.
2. **취약점 선공개** — 가르치거나 주장하기 전에 "나도 이거 엄청 못했어요"를 먼저. 권위를 낮춰 상대가 방어를 푼다(흥버튼이 일관되게 사용).
3. **나쁜 예 캐릭터화** — 지적을 사람으로 향하지 말고 "0.7의 남자" 같은 *가상 캐릭터*에게. 안전하게 웃기고 교훈은 남는다.
4. **실시간 동참 루프** — "한번 해볼까요?" 로 상대를 행동에 끌어들인다. 듣기만 하던 사람이 참여자가 된다.
5. **콜백 적립** — 대화 초반의 사소한 사건(말실수·농담)을 메모해뒀다 후반에 재소환. "우리만의 맥락"이 친밀감을 만든다.
6. **3박자 턴("받기→보태기→넘기기")을 의식** — 맞장구 후 내 사례에서 *멈추지 말고* 질문으로 닫는다. ③에서 발견한 핵심 리듬.
7. **끝맺음 설계** — 피크엔드 법칙. 자리/통화/회의를 "살짝 아쉬울 때 + 좋은 한마디"로 닫는 걸 *미리* 정해둔다.
