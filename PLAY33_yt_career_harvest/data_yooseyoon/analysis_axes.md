# 유세윤 개그 분석 — 6축 설계

사용자 요구를 빠짐없이 덮도록 설계: 개그 **사고방식**(발상) / **짜는 법**(설계) / **치는 법**(딜리버리) / **말하는 타이밍**(템포·빈도·양) / 실시간 합.

| 축 key | 한글명 | 무엇을 잡나 |
|---|---|---|
| `premise_angle` | 발상·관점 (사고방식) | 어디서 웃음 포인트를 잡는가 — 무엇을 비틀고 어떤 각도로 현실을 보는가. "이걸 왜 웃기다고 생각했나"의 사고 경로. |
| `joke_construction` | 개그 설계 | setup→punchline 구조, 빌드업, 룰 만들기, 전제 깔기, 콜백·반복, 미스디렉션·반전. 짜는 방식. |
| `timing_tempo` | 타이밍·템포·양 | 뜸/사이(pause), 박자, 빠르기, 치고 빠지기, 한 번에 쏟는 양 vs 절제, 침묵 활용, 언제 멈추나. **사용자 핵심 관심.** |
| `delivery_persona` | 딜리버리·페르소나 | 능청/시치미(deadpan), 톤·정색, 자기 캐릭터(능글·뻔뻔·진지한 척·찌질), 목소리 연기, 표정·몸(★전사 한계 명시). 어떻게 치는가. |
| `interaction_play` | 받아치기·합 | 상대 말 받아 비틀기, 판 깔기/패스, 디스·자학, 멍석말이, 리액션 유도, 케미. 실시간 즉흥. |
| `bit_craft_writing` | 작법·컨셉 | UV/콩트/노래의 컨셉 설계, 가사·언어유희·과장·말장난, 메타개그(개그를 개그라고 들키게), 캐릭터 컨셉. 만들어진 개그의 재료. |

## 카드 스키마
```jsonc
{
  "card_id": "Y101",
  "source_video": {"video_id":"...", "channel":"...", "title_hint":"..."},
  "axis": "<6축 중 하나>",
  "move": "실행 가능한 구체 기법 한 줄 (추상 구호 금지)",
  "how_it_works": "왜 웃긴지 메커니즘 1~2줄",
  "evidence_quote": "자막 직접 인용 1~2줄 (필수)",
  "timing_note": "이 수의 타이밍/템포/양 특징 (사이·빠르기·치고빠짐). 해당없으면 빈 문자열",
  "who": "유세윤 | 상대 | 미상 (화자분리 없어 문맥추론, 신뢰도 confidence에)",
  "counter": "이 수의 한계 / 안 통할 때 (없으면 빈 문자열)",
  "confidence": "high|medium|low — 사유"
}
```

## 규칙
- 자막에 실제 있는 것만. evidence_quote 없는 카드 금지. 창작 금지.
- Whisper 노이즈(VAD 환각 반복·고유명사 오타) 의미로 교정, 광고/채널인사 버림.
- 화자분리 없음 → 턴 귀속은 문맥추론, 신뢰도 medium 표기.
- 노래(UV/MV)는 Whisper가 가사를 부분만 받아씀 → 가사 인용은 confidence 낮춰 표기.
- **딜리버리/타이밍의 비언어(표정·몸짓·정확한 pause 길이)는 음성 전사로 부분만 잡힘** → 추론한 부분은 명시.
