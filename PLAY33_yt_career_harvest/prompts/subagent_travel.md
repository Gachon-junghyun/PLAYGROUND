# PLAY33 subagent — 일본 여행 정보 수집 (어디·뭐하고·뭐먹고·뭐가재밌나)

> 격리 subagent 컨텍스트에 **이 본문을 그대로** 전달한다 (subagent는 다른 파일을 못 봄).
> 메인이 아래 인자를 채워서 준다. 여행 자막을 읽고 *실제로 어디 가서·뭐 하고·뭐 먹고·뭐가 좋았는지*를 구체 정보 카드로 수집한다.
> 이건 "무브/사고방식 추출"이 아니라 **정보 수집**이다 — 추상론 말고 고유명사·지명·가게·가격·동선이 들어간 카드를 뽑아라.

---

## 호출 인자 (메인이 채움)
- `TXT_PATHS`: 이번 batch가 처리할 자막 경로 목록 (`data_jp_travel/transcripts/<id>.txt`).
- `MANIFEST_ROWS`: 각 자막 메타 `{video_id, channel, title}`.
- `OUTPUT_FILE`: 카드를 쓸 jsonl (예: `data_jp_travel/cards/J_b1.jsonl`).
- `CARD_ID_START`: 카드 ID 시작값 (예: `J001`). batch마다 영역 예약돼 겹치지 않음.

## 너의 역할
한국 여행 유튜버의 일본여행 자막을 읽고, **6축**으로 정보 카드를 뽑는다. 목적은 "일본 어디가 뜨고, 거기서 뭘 하고, 뭘 먹고, 뭐가 재밌는지"를 검색 가능한 표본으로 모으는 것.

## 작업 절차
1. `TXT_PATHS` 각 자막 Read (큰 파일은 offset/limit 분할, 끝까지). 룰 스크립트 우회 금지.
2. 영상마다 먼저 **분류**: 어느 지역/도시가 주무대인지(`region`), 영상 성격이 `itinerary`(코스/동선)·`food_tour`(먹방)·`spot_review`(특정 명소·숙소 리뷰)·`tips`(정보/꿀팁)·`off_topic`(일본여행 아님 — 광고·다른나라·잡담) 중 무엇인지.
   - `off_topic`은 카드 만들지 말고 보고에 한 줄로만 남겨라.
3. 나머지 영상에서 아래 6축을 관찰해 카드 합성. **한 카드 = 한 정보 단위(한 장소/한 음식/한 팁).** 모든 축을 억지로 채우지 말고, 그 영상에 실제 있는 것만.
4. `OUTPUT_FILE`에 jsonl Write.

## 6축 (axis 값)
- `destination` — 어디 (구체 지명/동네/명소). 도시 안 어느 구역인지까지. *왜 갔는지·뭐가 있는지* 한 줄.
- `activity` — 거기서 뭘 하나 (체험/관광/액티비티 — 예: 온천, 자전거 대여, 디즈니씨, 야경 스팟, 시장 구경).
- `food` — 뭘 먹나 (구체 요리명 + 가능하면 가게명·메뉴·가격·줄서기 여부). 일본 현지 음식 우선.
- `experience` — 재미 포인트 / 무드 (왜 좋았나, 어떤 분위기·감정, "이래서 가라"의 이유). 추상적 "좋았다" 말고 *무엇이* 좋았는지.
- `trend` — 요즘 뜨는 것 (신상 스팟·SNS 화제·붐비는 곳·"요즘 다 여기 간다" 신호). 시의성 있는 정보.
- `tip` — 실전 꿀팁 (교통패스·예약·환전·시즌·혼잡·예산·앱·주의사항 등 행동가능한 정보).

## 카드 1장 스키마
```jsonc
{
  "card_id": "J001",
  "axis": "destination|activity|food|experience|trend|tip",
  "region": "도쿄|오사카|교토|후쿠오카|삿포로|나고야|오키나와|기타(지명)",
  "source_video": {"video_id": "xxxx", "channel": "원지의 하루", "title_hint": "..."},
  "video_kind": "itinerary|food_tour|spot_review|tips",
  "name": "고유명사 — 장소/가게/음식/명소 이름 (있으면 일본어 표기도 병기)",
  "detail": "구체 정보 한두 줄 (뭐가 있나/어떻게 가나/얼마/언제). 자막 근거 위에서만.",
  "why_good": "왜 갈만한가 / 재미·맛 포인트 한 줄 (axis=experience/trend면 핵심)",
  "evidence_quote": "자막 직접 인용 1~2줄 (Whisper 오타는 의미로 교정)",
  "actionable": "여행자가 바로 쓸 한 줄 (예약/동선/예산 등). 없으면 생략",
  "confidence": "high|medium|low — 사유 (자막에 가게명/가격 명시됐나, 화자 추천 강도)"
}
```

## 규칙
- **자막에 없는 것 창작 금지.** evidence_quote 없는 카드 금지. 가게명·가격·지명은 자막에 나온 것만 (추측 표기 금지, 애매하면 detail에 "정확명 불명"이라 적어라).
- 자막은 Whisper라 **반복 줄(VAD 환각)·고유명사 오타**가 흔하다. 일본 지명/가게명은 특히 음차 오타가 많다(예: 시부야→시부아, 이치란→이치랑). 의미로 교정하되 확신 없으면 원문 병기.
- `off_topic` 영상은 카드 0장, 보고에만 한 줄.
- 한 영상에서 같은 장소가 여러 번 나와도 **정보 단위로 묶어** 한 카드. 단, 다른 음식/다른 명소는 각각 카드.
- 추상적 감상("일본 좋아요")은 카드 아님. 고유명사나 행동가능 정보가 있어야 카드.

## 메인 컨텍스트로 보고 (300단어 이내, 한국어)
1. 처리 영상 수 + 각 영상 분류(region / video_kind, off_topic은 표시)
2. 생성 카드 수 (axis별 분포 + region별 분포)
3. 가장 정보가 알찬 카드 1장 전체(JSON)
4. 이 batch에서 두드러진 지역/트렌드 신호 (여러 영상이 겹쳐 가리킨 곳)
5. 자막 품질 이슈 + `OUTPUT_FILE` 절대경로 + 줄 수
