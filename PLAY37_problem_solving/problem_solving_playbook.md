# 문제해결능력, 현실에서 쓰는 법 — 7개 자리 플레이북

> 유튜브 20편(인지심리·컨설팅·공부법·창업)에서 문제해결의 **추상 프레임(5회로·카드 109장)**을 역추출한 뒤,
> subagent 워크플로우로 **보드게임·전시발표·공부·일처리·놀러간자리·위기돌발·인간관계** 7개 현실 자리에 적용→깐깐한 현실주의자가 검증해
> "그 자리에서 진짜 하는 것만" 추린 결과물. 추상 원리는 §2, 바로 쓸 플레이북은 §4.
> 근거: `problem_solving_report.md`(프레임) + `scenario_findings.json`(시나리오 검증 raw).

---

## 1. 한 줄

문제해결능력은 "머리가 좋다"가 아니라 **다섯 회로를 의식적으로 도는 습관**이다. 그런데 현실에 갖다 대보니 — 그 회로들은 **이름표를 떼고 "한 동작/한 마디"로 압축할 때만** 살아남았고, **종이에 트리 그리기 같은 건 즉흥·사교·위기 자리에선 통째로 죽었으며**, 진짜 승부의 절반은 프레임이 통째로 빠뜨린 **사교·감정·타이밍** 무브에서 갈렸다.

## 2. 추상 프레임 — 문제해결 5회로 (압축판)

이름은 외울 필요 없다. 막혔을 때 이 다섯 개를 순서대로 한 번씩 자문하면 된다.

| 회로 | 핵심 질문 | 대표 무브 (카드ID) |
|---|---|---|
| **① 문제정의** | "어떻게"가 아니라 **"왜 이게 진짜 문제지?"** | 현상≠문제, '왜>어떻게'(X403), 5why로 근본원인(X401), 가장 약한 고리 하나(X405) |
| **② 구조 외부화** | 머릿속 말고 **종이/말로 빈 틀을 그렸나?** | 로직트리·MECE(X408), 피시본(X316), 다이어그램(X413), 노드마다 3개(X312) |
| **③ 가설→검증→집중** | **가설부터 던지고, 핵심 하나에 몰았나?** | 자료보다 가설 먼저(X416), 80/20(X421), 병목부터(X304), 작게 파일럿(X328) |
| **④ 메타인지** | **내 직관·아는 척·편향을 의심했나?** | 모름 인정(X214), 완성의 착각 버리기(X213), 핸런의 면도날(X429), 입장 스위치(X217), 보조선(X205) |
| **⑤ 전이** | **푼 걸 원리로 만들어 다른 데 쓰나?** | 제1원리(X424), 멘탈모델 격자(X427), 세컨드오더(X428), 일반화(X204) |

> 자세한 축별 정리·근거 인용은 `problem_solving_report.md` 참조.

## 3. 핵심 발견 — 추상 프레임은 현실에서 어떻게 살아남고, 어디서 죽는가

7개 자리에 다 굴려보니 패턴이 선명했다. **이게 이 연구의 진짜 결론이다.**

**✅ 잘 살아남는 것 (거의 모든 자리)**
- **회로④ 메타인지** — 가장 범용. 보드게임 상대 수 뒤집기, 발표장 핸런의 면도날(반박을 공격으로 안 받기), 갈등 전 "내 자작 서사 아닌가" 점검까지 그대로 먹힌다. *말 한마디·머릿속 0.5초*로 실행되기 때문.
- **회로③ 집중(80/20·병목·조건 줄이기)** — "다 하지 말고 하나" "조건 깎기"는 어디서나 마비를 푼다.
- **회로① 문제정의의 알맹이** — 단 'SMART로 재작성' 같은 형식은 죽고, **"진짜 막힌 건 이거야"를 한 문장으로 선언**하는 알맹이만 산다.

**❌ 자주 죽는 것**
- **회로② 구조 외부화(종이에 로직트리·점수표)** — 시간 있고 혼자인 **공부·일처리에서만** 산다. 보드게임·놀러간자리·위기·갈등에선 *그릴 시간도 없고, 그리는 순간 분위기가 깨져* 아무도 안 한다.
- **회로⑤의 형식 이름**(피라미드·세컨드오더) — 알맹이(결론 먼저, 2차 결과 1초)만 살리고 명명은 버려야 함.

**🕳️ 프레임이 통째로 빠뜨린 것 (= 코퍼스가 일·공부 편향이라 생긴 사각지대)**
모든 시나리오에서 skeptic이 똑같이 지적했다. **이게 빠지면 회로 다 돌려도 현실에선 진다.**
- **사교·관계 무브** — 5초 역할분담(방탈출), 거래·공동의 적 만들기(카탄), 라포 5초(발표), 단독결정으로 합의시간 녹이기 막기(여행).
- **감정 조절** — 위기의 호흡·안전게이트, 갈등의 쿨다운·"네가 서운했겠다"(validation), 공부의 collapse("됐어 내 스타일 아냐") 막기.
- **타이밍** — "N분 안 되면 손절"(타임박스), 갈등은 "지금은 말할 때 아님".
- **즉흥 종결** — 못 정하면 동전던지기/사다리타기로 5초 컷(관계비용 절감).

> **결론:** 추상 프레임은 **'판단의 골격'으로는 70점**짜리 범용 도구다. 하지만 **'그 자리에서 따라 하는 절차'로는 절반**이다 — 이름표를 떼고 한 동작으로 압축하고, 빠진 사교·정서·타이밍 무브를 끼워야 비로소 현실에서 합격선을 넘는다.

## 4. 7개 자리 플레이북 — "이런 순간이 오면 → 이렇게 한다"

각 표는 그 자리에 실제로 처한 현실주의자가 "진짜 하는 것만" 추린 것. (괄호=근거)

### 🎲 보드게임 / 방탈출
| 이런 순간이 오면 | 이렇게 한다 |
|---|---|
| 다 같이 한 단서를 5분째 우려먹는 중 | 손가락으로 가리키며 한 문장: "막힌 건 이 자물쇠가 아니라 **이 숫자 출처를 모른다**는 거야. 출처부터 찾자" (X404) |
| 시작했는데 다들 한곳에 몰리거나 따로 논다 | 5초 분배: "나 왼쪽 벽, 너 서랍, 둘은 자물쇠. 찾으면 소리쳐" (프레임에 없던 *역할분담*) |
| 자물쇠 한 번 시도했는데 틀림 | 같은 거 또 누르지 말고 "**이 해석 자체가 틀렸다**" 선언 → 그 단서를 후보에서 제거 (X419) |
| 5분 남았는데 안 푼 자물쇠 2개+ | 다 매달리지 말고 단서 제일 많은 하나에 전원 투입, "2분 안 되면 딴 거" 타임박스 (X421+*손절*) |
| 카탄 중반 나만 한 자원이 안 풀림 | 병목 자원 딱 하나(양/광석) 짚고 그것만 노린다. 동시에 여러 개 고치려 말 것 (X405) |
| 내 턴 직전, 1등이 곧 이길 분위기 | "내가 1등이면 다음에 뭐 하지" 한 수 그려보고 그 길목을 막는다 (X217) |
| 누가 거래 거절·나 견제함 | "쟤가 날 싫어하네"(악의)로 몰지 말고 "걍 자기 이득"으로 보고, "저 1등 같이 막자"로 연합 (X429+*관계*) |
| 주사위·카드 운이 나쁘게 터짐 | 한탄 말고 흘려보낸다 — 통제 불가. "바뀐 판 최선의 수"만 다시. 운은 즐기는 것 (*운 수용*) |

### 🪧 전시 / 발표 (내 결과물 보여주고 질문 받기)
| 이런 순간이 오면 | 이렇게 한다 |
|---|---|
| 질문·반박이 날아옴 (30초밖에 없음) | **결론 한 줄 먼저**: "한 줄로 답하면 X입니다." 시간 남으면 이유 1개만. 3개 다 풀려 하지 마라 (X434+X421) |
| "기존 거랑 뭐가 달라요?" 류 | 기능 차이 나열 금지. "**그래서** 사용자가 B상황에서 30초 아낍니다"로 가치로 답 (X423) |
| 답 진짜 모르는 날카로운 질문 | 지어내지 말고 톤 안 떨고: "거기까진 아직 검증 안 했어요. 어떤 케이스 말씀이세요?" (X214+*자신감 톤*) |
| 반박조 질문이 공격처럼 느껴질 때 | 속으로 "그냥 궁금한 거다" 깔고, 입으론 "좋은 지적이에요, 사실—". 변명조 금지 (X429) |
| 누가 부스 앞에 막 다가온 첫 5초 | 눈맞춤+"와주셔서 감사해요" 깔고 "한마디로 ___ 만드는 거예요"로 후킹 (X102+*라포*) |
| 말로는 안 와닿는 표정 | 설명 멈추고 "직접 해보실래요?" 손에 쥐여준다. 전시는 논증이 아니라 *체험 전달* (*시연*) |
| 한 명이 길게 무는데 뒤에 줄 생김 | "끝나고 따로 잡아도 될까요?" 하고 명함으로 넘기고 다음 사람 (*대기열 분배*) |

### 📚 공부 (안 풀리는 문제·개념·시험)
| 이런 순간이 오면 | 이렇게 한다 |
|---|---|
| 읽어도 안 들어오고 형광펜만 그음 | 종이에 한 줄: "**개념 모름 / 공식은 아는데 언제 쓸지 모름 / 계산만 막힘** 중 어디?" 못 짚으면 거기가 문제 (X403) |
| 예제는 풀리는데 응용만 막힘 | 책 덮고 **백지에 그 개념을 남에게 설명**(파인만). 말 막히는 첫 문장이 진짜 모르는 곳 (X207+X408) |
| 한 문제를 15분+ 붙잡고 첫 줄도 못 씀 | **타임박싱**: 15분 막히면 해설 첫 줄만, 30분이면 전체 보고 표시 → 다음 날 답 안 보고 다시. 무한정 붙잡기는 자학 (*타임박스*) |
| 풀이 첫 줄이 안 잡힘 | 답에서 **거꾸로**: "이 답 나오려면 직전에 뭐가 필요?" 변수엔 작은 숫자 넣어 손으로 굴림 (X205+X204) |
| 시험 범위 전체가 막막, 1p부터 정주행하고 싶음 | 정주행 멈추고 **기출부터**. "이 단원은 2~3유형의 변형" 가설 세우고 자주 나오는 20%부터 (X416+X421) |
| 틀렸다 / 해설 봄 | 오답노트에 "왜 틀렸나"를 개념·계산·독해 중 분류 → 밑에 "이 유형은 [조건 A면 B]"로 한 줄 일반화 (X430+X204) |
| 오늘 이해한 거 있음 | 다음 날·3일 뒤 **책 안 보고 백지 인출(re-test)**. "봤다=안다" 아님 (*인출·간격반복*) |
| 40분 막혀 "됐어 내 스타일 아냐" 덮고 싶음 (collapse) | 5분 걷고 옴 → "못 푼 게 아니라 **아직 안 푼 것**"으로 리프레임 → 타임박싱 규칙으로 (*collapse 대응*) |

### 💼 일처리 (모호하게 떨어진 업무·보고)
| 이런 순간이 오면 | 이렇게 한다 |
|---|---|
| 상사가 "이거 좀 알아봐줘"만 던지고 감 | 그 자리에서 용도를 묻는다: "어떤 **결정** 내리시려고요? 거기 맞춰 깊이 잡을게요" (X403+*정치적 포장*) |
| 자리로 돌아온 직후 | 내 언어로 범위를 한 줄로 써서 **컨펌**: "경쟁사 3곳·6개월·A4 1장·화요일까지, 이 범위 맞죠?" 글로 박아 기대치 고정 (X407+*기록*) |
| 막막해서 다 뒤지고 싶은 충동 | **가설부터**: "핵심은 가격인하·신규채널 둘일 것." 그 둘만 30분 확인해 초벌 1장 (X416+X421) |
| 초벌 30~40% 시점 | 방향만 깐다 (딱 1회): "이 방향 맞아요?" 결론 1~2개만. 자잘한 건 안 물음 (X426+*중간보고 타이밍*) |
| 진짜 갈림길이라 모르겠음 | "모르겠다" 대신 **선택지로**: "A 아니면 B 같은데 어느 쪽?" (X214) |
| 최종 보고 시작하는 순간 | **결론부터**: "핵심 3가지입니다…그래서 우리가 할 수 있는 건 X,Y." 자료 나열·통제불가 진단("시장이 어렵다") 금지 (X434+X423+X402) |
| 1인/프리랜서, 카톡으로 "급해요"만 옴 | 범위·산출물·기한을 **글로 못박고** 답 받음: "X를 Y형태로 N일까지, 맞죠?" 말 바꿈 대비 (*기록=증거*) |

### 🏖️ 놀러간 자리 (계획 틀어짐·즉흥 결정)
| 이런 순간이 오면 | 이렇게 한다 |
|---|---|
| 펜션 펑크·길 잃음, 멘붕·짜증 시작 첫 30초 | **톤부터**: "아 ㅋㅋ 완전 망했네, 안주각이다" 한마디로 짜증을 웃음으로. 해결책은 그다음 (*감정 먼저*) |
| 의견 갈려 같은 말 5분째 | 선택지 2~3개로 자르고 "셋 셀 테니 손 들자" **즉석 거수**. 비교분석 말고 교통정리 (X434 변형) |
| 거수해도 반반, 진 사람 생기는 미묘함 | "모르겠다 동전 던지자" **5초 무작위 종결**. 누구도 틀린 사람 안 되게 운에 (*체면 보호*) |
| 6명이 합의하려다 시간만 녹음 | 덜 예민한 한 명이 "**내가 정한다**, 진짜 싫은 사람만 말해". 반대 없으면 출발 (*단독결정*) |
| "가깝고+싸고+뷰좋고…" 조건으로 마비 | 조건 **하나로 깎기**: "오늘은 잘 곳만, 가깝기만." 그걸로 "내가 30초 검색해 찍을게" (X118+X417) |
| 큰 결정 무서워 못 내림 | 되돌릴 수 있는 **5분 임시안**: "일단 저 카페서 비 그치나 보고 다시 정하자" (X328) |
| 예약 펑크로 한 사람한테 분위기 쏠림 | 화살을 **사물로**: "예약사이트가 엿같네." 자책도 막고 분위기도 안 깸. "너 때문" 금지 (X429) |
| 한 명이 말없이 폰만 봄 (침묵=동의 착각) | 직접 "넌 솔직히 어떻게 하고 싶어?" 끌어들임. 나중에 삐지는 거 미리 차단 (X217 변형) |

### 🚨 위기 · 돌발 (고장·사고·펑크) — *순서가 생명*
| 이런 순간이 오면 | 이렇게 한다 |
|---|---|
| 사고/고장 인지한 첫 3초, 머리 하얘짐 | 길게 **한 번 내쉰다**(내쉬기). 입으로 "다친 사람? 더 망가질 거?" 없으면 다음 (*호흡+안전게이트*) |
| 위험원이 아직 활성(차로 위·미저장·불·물) | 분석 0초, **출혈부터**: 비상등·갓길 / Ctrl+S·복사 / 차단기. "왜"는 끄고 나서 (*stop the bleeding*) |

## 5. 한 장 치트시트 — 어떤 자리든 막히면

1. **숨 고르고(위기·갈등이면 먼저) → 진짜 문제를 한 문장으로 말한다.** ("막힌 건 X가 아니라 Y야")
2. **다 하려 하지 말고 하나에 건다.** (병목·핵심 20%·조건 깎기)
3. **가설부터 던지고, 틀리면 정보로 회수한다.** (완벽 정보 안 기다림 / 틀린 시도 = 후보 제거)
4. **내 직관·아는 척·악의 추정을 한 번 의심한다.** (핸런의 면도날 / 백지 설명 / 상대 입장)
5. **시간·사람·감정을 챙긴다.** (타임박스 손절 / 역할분담·부탁 / 톤 먼저)
6. **끝나면 한 줄로 원리를 남겨 다음에 옮긴다.** (멘탈모델 한 줄)

> 자리가 **혼자·시간 있음(공부·일)**이면 종이에 구조를 그려라(회로②가 산다).
> 자리가 **즉흥·사람 많음(놀이·사교·위기)**이면 종이 버리고 한 동작/한 마디로 압축하고, **사교·감정·타이밍**을 먼저 챙겨라.
