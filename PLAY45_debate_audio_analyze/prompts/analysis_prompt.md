# 화자 분리 + 논증 분석 프롬프트

`output/transcript.txt` (+ `output/segments.jsonl`) 가 준비되면, LLM(예: Claude)에게
아래 프롬프트로 분석을 시킨다. 결과는 `output/analysis.md` 로 저장.

> pyannote 화자 분리를 안 쓰므로(아래 README 참조), 화자 A/B 귀속은 **전사본의
> 발화 전환·내용·말차례(turn-taking)** 로 LLM 이 추정한다. 구조화된 두 사람 토론에서는
> 턴이 길어 비교적 안정적이지만 100%는 아니다 — 애매한 구간은 결과에 [불확실] 표시.

## 프롬프트

너는 토론 분석가다. 아래는 종교(기독교) 주제 2인 토론의 전사본이다.
타임스탬프 단위로 발화가 끊겨 있다. 다음을 수행하라.

### 1. 화자 분리
- 발화 전환·말투·입장에서 화자를 **A / B** 두 명으로 귀속하라.
- 각자의 기본 입장(positive/negative, 또는 옹호/반박)을 한 줄로 요약.
- 귀속이 애매한 구간은 `[불확실]` 로 표시하고 근거를 적어라.

### 2. 화자별 주장 지도 (각 화자에 대해)
- **핵심 주장**: 이 사람이 관철하려는 결론들 (불릿).
- **논증 관절**: 각 주장의 (전제 → 추론 → 결론) 구조를 복원. 숨은 전제도 드러내라.
- **정의 장악**: 핵심 용어(신, 믿음, 증거, 선/악 등)를 누가 어떻게 정의했고,
  그 정의가 이후 논의를 어떻게 유리/불리하게 묶었는지.

### 3. 평가 (각 화자에 대해)
- **괜찮은 것**: 타당한 추론, 좋은 입증, 상대 허점을 정확히 찌른 지점.
- **부족한 것**: 논리 결함을 *유형*으로 명명하라 —
  비형식 오류(허수아비·미끄러운 경사·순환·거짓딜레마·권위 호소·논점 일탈 등),
  입증책임 전가, 정의 슬쩍 바꾸기, 미응답(상대 핵심에 답 안 함), 과일반화.
  각 항목에 전사본 근거(타임스탬프나 인용)를 달아라.

### 4. 교전 분석
- 두 사람이 실제로 *맞붙은* 쟁점 vs 서로 빗나간(엇갈린) 지점.
- 결정적 순간: 한쪽이 우위를 잡았거나 놓친 분기점(타임스탬프).

### 5. 한 줄 총평 + 각자에게 줄 코칭 1개
- 누가 더 설득적이었나, 왜. 감정 아닌 논증 근거로.
- A 에게, B 에게: 다음에 같은 토론을 한다면 바꿀 무브 하나씩.

### 출력 형식
한국어. 마크다운. 인용은 `"…" [12:34]` 처럼 타임스탬프와 함께.
추측은 추측이라고 밝혀라. 전사 오인식으로 보이는 부분은 `(전사오류?)` 표기.
