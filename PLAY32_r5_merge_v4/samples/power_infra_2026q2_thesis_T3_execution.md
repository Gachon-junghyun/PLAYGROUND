## Step 1 — F53 미시 단위 분해 (4 검증 질문)

**Q1**: 하위 단위별 대체경로(설비·기술·물류)가 실제로 차단되어 있는가?

→ **수행**: 한국 전력 시장 단위 = 한전(독점 매수자) ↔ 발전사(다수 매도자, SMP 자동 연동) ↔ 가스공사(LNG 도매 정치 가격).

- 한전 매입가 ↔ 가정·산업 소매가 **차단** (정치적 요금 결정. 5/26 한경 "전기요금제 몰라도 싼 요금 자동 적용" — 가정용 정치적 보호 재확인).
- 한전 매입가 ↔ 산업용 요금 일부 연동 (단, 4/29 mk "전기차 충전비 출력별 차등제…초급속 요금 20% 인상" — 정치적 요금 인상은 *주변부 EV 충전*에 한정).
- 발전사 → 한전 단방향 판매. SMP 자동 연동 = **제도적 전가 보장**.
- → **Q1 답: 한전의 소매 채널은 차단, 발전사의 SMP 채널은 자동 연동.** F53 발화 조건 충족.

**Q2**: 물리 제약이 가격탄력성을 어떻게 바꾸는가?

→ 한전: 가정용 요금 인상 정치 비용 = 무한대 (선거 시즌 6월 직전). 산업용도 제한적. **공급가는 자유, 판매가는 정치 락**.
- → 한전의 *비탄력성*은 *판매가 lock-in*에서 옴.

**Q3**: 분리된 단위 가격 시계열이 decoupling을 보이나?

→ **데이터 확인** ([news_alert.db sedaily 2026-05-13](https://www.sedaily.com/article/20043593)):

| 지표 | 한전 1Q26 | 가스공사 1Q26 |
|---|---|---|
| 영업이익 | 3.8조 (컨센 4.2조 **미달**) | 9,100억 (+9.1% YoY) |
| 매출 | 24.4조 (+0.7%) | 11.8조 (**-7.3%**) |
| 핵심 변수 | 단위 연료비 57원/kWh (**+8.1%**) | 가스 판매단가 *하락* |
| 미수금/충당 | (회사채 한도 반토막) | **민수용 도시가스 미수금 13.4조** |

→ 표면 decoupling 확인. **다만 가스공사 영업이익 증가는 일회성**(강관입찰담합 승소금 + 해외배당 차이 + 자회사 영업이익) — 본업이 좋아진 게 아님. 가스공사도 한전과 동일하게 *민수용 도매가 인상 못 함* (선거 직전).

→ **Q3 답: 회계 decoupling은 표면적, *비즈니스 모델 decoupling은 약함*.** 가스공사는 한전과 다른 회사처럼 보였지만 *같은 정치 그릇*. 이게 시드 카드가 안 다룬 부분.

**Q4**: 대체경로 차단이 단기인가 영속인가?

→ 한전 소매가 통제는 *정치 사이클* 종속. 6/3 지방선거 직전 = 절대 인상 X. 선거 직후~9월 = *부분 인상 옵션*(LP 발언 의존). 9월 이후 = SMP 상한제 부활 옵션도 정치적 변수.
- → 단기 (3개월) **확실 차단**, 중기 (6개월) **정치 사이클로 부분 해제 가능**, 장기 영속 **아님**.

## Step 2 — F75 채널 분리 (4 검증 질문)

**Q1**: 각 채널 영향 강도 정량 모델로 분리 가능?

→ **유가 → 한전 채널**: 1Q26 단위 연료비 +8.1% → 연료비 5.2조 (전체 매출 21%) → 영업이익 -4,000억 추산 (시드 카드 추가 anchor).
→ **유가 → SMP 채널**: 교보 이상호 연구원 "4~6개월 후 SMP 상승" — 정량 모델 부재, **lag 4~6M 추정**. SMP/유가 회귀계수 직접 데이터 못 잡음 → 정보 공백.
- **Q1 답: 한전 채널은 정량 분리됨, SMP 채널은 lag 정성 추정 수준.** 비대칭 모델의 *수혜 측 정량 anchor가 약함*.

**Q2**: 약하다고 본 채널이 구조적·지속적이고 강하다고 본 쪽이 일시적일 가능성?

→ 분석가는 한전 = 패자, 발전사 = 승자로 분리. 데이터 확인:
- 한전 패자 = **구조적**(정치 lock-in, 회사채 한도 반토막, 5사 목표가 일괄 하향)
- 발전사 승자 = **표면적**. 진짜 SMP 자동 연동 *상장* 종목 매핑이 빈약 — 한국가스공사는 *민수용 정치 통제 그릇*, 한전 자회사 발전사 5개(동서·서부·남부·중부·남동) 모두 한전 100% 자회사라 *한전 연결로 함께 패자*. **순수 IPP 상장 종목 = 사실상 없음**(GS EPS·SK E&S·포스코에너지 모두 비상장).
- → **Q2 답: 패자 쪽이 구조적 확인, 승자 쪽 상장 매핑 빈자리.** F87 anti_signal의 *3번째 무력화 조건* 발견.

**Q3**: 채널별 효과 지속 기간이 다르면 단기 vs 중기 순효과 부호 뒤집히는가?

→ 시간 함수 분해:
- **단기 (1~3M, 5~7월)**: 유가↑ → 한전 매입원가 즉시 반영, SMP는 4~6M lag (교보 코멘트). → 한전 패자, 발전사 *아직 미발화*.
- **중기 (4~6M, 8~10월)**: SMP↑로 발전사 매출↑ + 한전 매입원가 추가↑. → 발전사 발화, 한전 추가 패자.
- **6M~ (11월~)**: SMP 상한제 부활 가능성 (호르무즈 장기화 시나리오 트리거). → 발전사 다운사이드, 한전 부분 회복.
- → **Q3 답: 분기별 수혜자 회전.** 시드 카드의 "발전사 승자" 진술은 8~10월 한정. 11월 이후 부호 뒤집힘 가능.

**Q4**: 비대칭 판단 핵심 전제(SMP 상한제 부재)가 무너지면?

→ news_alert.db 30일 sweep — **"SMP 상한제" 보도 0건**. 정책 검토 신호 부재. **시드 카드의 "호르무즈 장기화 시 부활" 가설은 분석가 예상, 데이터 발화 아직 없음**.
- 산업부 보도자료·국회 에너지위 의사록 추가 모니터링 필요.
- → **Q4 답: anti_signal 발화 신호 모니터링 setup이 핵심**. 다음 4~6주 키워드 alert 등록.

## Step 6 — 진짜 결론 (Step 1~5 종합)

**T3 시드 카드 B089 thesis status**:
