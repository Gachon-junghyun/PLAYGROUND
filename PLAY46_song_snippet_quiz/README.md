# PLAY46_song_snippet_quiz

## 목적
음악을 1초만 듣고 맞히는 게임(Heardle 스타일). SPACE 로 곡의 한 구간을 반복해 듣고, 듣는 시간을 직접 늘리거나 [🔀 랜덤 섞기]로 같은 곡의 다른 부분을 들어보며, 4지선다 보기를 클릭해 맞힌다. 곡 오디오는 유튜브에서 받아온다(PLAY33 의 yt-dlp 패턴 차용, 코드는 독립).

## 실행법
```powershell
# 1) 의존성 (한 번만)
pip install pygame yt-dlp
#   + ffmpeg / ffprobe 가 PATH 에 있어야 함 (mp3 변환·길이 측정용)

# 2) 곡 받기 (clips/*.mp3 + playlist.json 생성). 이미 받은 곡은 건너뜀.
python download.py                # 기본 12곡 전부
python download.py --limit 4      # 앞 4곡만 (빠른 확인)

# 3) 게임 실행
python game.py
```
> 이미 기본 12곡(BTS·PSY·NewJeans·Ed Sheeran·Queen·Adele 등)을 받아뒀으니 바로 `python game.py` 로 시작 가능.

### 곡 바꾸기
`songs.txt` 를 만들어 한 줄에 `제목 - 아티스트` (아티스트 생략 가능) 형식으로 넣으면 기본 목록 대신 그걸 쓴다. `#` 로 시작하는 줄은 주석.
```
좋은 날 - 아이유
APT. - 로제 브루노마스
Espresso - Sabrina Carpenter
```
넣고 `python download.py` 다시 실행.

### 조작
- **SPACE** : 현재 구간을 *그대로 다시* 재생 (시작점·길이 안 바뀜). 처음엔 1초.
- **[− 시간] / [+ 시간]** (또는 **↓ / ↑** 키) : 듣는 시간을 직접 조절 — `1 → 1.5 → 2.5 → 4 → 6 → 9초`. 길게 들으면 쉽지만 점수는 낮아짐.
- **[🔀 랜덤 섞기]** (또는 **R** 키) : 같은 곡의 *다른 부분*으로 시작점 변경.
- **보기 클릭** : 정답 판정. 정답이면 초록, 오답이면 빨강 + 정답 표시.
- **다음 곡 →** (또는 판정 후 **Enter** 키) : 다음 라운드. 버튼은 판정 후에만 창 맨 아래에 뜬다. 시간은 다시 1초, 시작점도 새로 정해짐.

## 입력 / 출력
- **입력:**
  - `songs.txt`(선택) 또는 `download.py` 안의 `DEFAULT_SONGS`.
  - `playlist.json` — `[{title, artist, file, duration}]`. download.py 가 생성/갱신.
  - `clips/*.mp3` — 받은 오디오.
- **출력:** GUI 게임 창. 점수·연속 정답·진행 곡 수를 화면에 표시(저장은 안 함).

## 가정 & 제약
- **곡 식별은 유튜브 검색 1순위 결과**(`ytsearch1:<제목> <아티스트> official audio`)에 의존한다. 드물게 커버/리믹스/라이브가 잡힐 수 있음 — 그러면 해당 mp3 를 `clips/` 에서 지우고 `playlist.json` 에서 빼거나, `songs.txt` 로 더 정확한 곡명을 줘서 다시 받아라.
- **점수 공식:** 정답 시 `max(20, 100 - 시간단계*15)`. 듣는 시간이 짧을수록 고득점. 한 곡당 보기 클릭은 1회(클릭하면 판정 확정).
- **시작점은 곡당 한 번만 랜덤으로 정하고 고정**한다. SPACE 는 같은 구간을 반복 재생. [🔀 랜덤 섞기]를 눌러야 같은 곡의 다른 부분으로 바뀐다. (시작점은 최대 길이 9초를 재생해도 곡을 안 넘치는 범위에서 뽑음; 곡이 9초보다 짧으면 0초부터.)
- **저작권:** 받은 mp3 는 개인 로컬 플레이용. 배포·commit 하지 마라. `clips/` 와 `playlist.json` 은 깃에 올리지 않는 걸 권장(필요하면 `.gitignore` 추가).
- **오디오 길이 측정**에 `ffprobe` 사용. 없으면 duration=0 으로 빠져 playlist 에서 제외됨 → ffmpeg 풀빌드 설치 필요.
- **mp3 start 오프셋 정확도**는 pygame(SDL2) 구현에 맡김 — 게임 체감엔 충분하나 ms 단위로 정확하진 않다.
- **다운로드는 디스패치 부적합**: 12곡 받는 데 네트워크 시간이 걸려 Bash 45초 제한을 넘길 수 있다. download.py 는 로컬에서 미리 돌려두는 사전 준비 단계로 본다(이미 12곡 받아둠). 게임(game.py)은 네트워크 불필요.
- Windows / Python 3.11 에서 작성·확인. tkinter 는 표준 라이브러리.
