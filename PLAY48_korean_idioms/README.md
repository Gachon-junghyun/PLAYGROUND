# PLAY48_korean_idioms

## 목적
국립국어원 **표준국어대사전 '자세히 찾기'에서 구분=관용구 전체(약 3,886개)**를 긁어 한 줄씩 읽어볼 수 있는 엑셀(`korean_idioms.xlsx`)로 떨군다.

## 실행법
```powershell
# Python 3.11 기준. 의존성(이미 깔려 있으면 생략):
pip install requests beautifulsoup4 openpyxl

python PLAY48_korean_idioms\scrape_idioms.py
```
- 인터넷 필요(stdict.korean.go.kr 에 직접 붙음). 약 78페이지를 0.4초 간격으로 돌아 **대략 60초** 걸린다.
- 끝나면 같은 폴더에 `korean_idioms.xlsx` 생성. 콘솔 마지막 줄이 `DONE wrote N rows`.

## 입력 / 출력
- **입력:** 없음. 검색 조건은 스크립트에 고정(`searchWordKindCode=4` = 관용구, 어종 전체).
- **출력:** `korean_idioms.xlsx`
  - 컬럼: `번호 | 표제어 | 원어(한자 등) | 뜻풀이 | 사전 링크`
  - 표제어 예: `가꾸로 박히다`, 뜻풀이 예: `머리를 땅으로 향한 채 떨어지다.`
  - `사전 링크`는 해당 항목의 표준국어대사전 상세 페이지(`searchView.do?word_no=...`) 하이퍼링크.
  - 헤더 고정(freeze)·자동필터 적용해서 바로 정렬/검색 가능.

## 가정 & 제약
- **"관용구로 엑셀 리스트" 해석:** 화면의 구분=관용구 체크 한 상태(어종 전체, 품사/전문분야/다중매체/날짜 전체)를 그대로 재현. 표제어만이 아니라 **뜻풀이까지** 넣었다 — "한번씩 읽어보게"라는 요청에 정의가 있어야 읽는 의미가 있으므로. 정의 없이 표제어만 원하면 D열만 지우면 됨.
- **한 항목 = 한 행.** 동형 관용구(표제어 같고 word_no 다른 것)는 각각 별도 행으로 유지. 중복 제거는 word_no 기준이라 같은 항목이 두 번 들어가지 않음.
- **뜻풀이 여러 의미**(「1」「2」…)는 ` / `로 이어 한 칸에 넣음.
- **개수 검증:** 스크립트가 페이지 상단의 "총 N개"를 읽어 누적 수집분과 비교, 차이가 나면 콘솔에 경고. 사이트가 표제어 수를 바꾸면(사전은 수시 갱신) N이 3,886과 달라질 수 있음 — 그건 오류가 아니라 사전이 갱신된 것.
- **사이트 의존:** stdict의 폼 파라미터/HTML 구조(`a.t_blue1`, `font.dataLine`, `fnSearchView('word_no','4')`)에 의존. 국립국어원이 마크업을 바꾸면 파서가 깨질 수 있음. 그때는 `scrape_idioms.py`의 `parse_rows` / `BASE` 갱신 필요.
- **실행 시간:** ~60초로 디스패치 Bash 45초 한도를 넘길 수 있음. 디스패치로 돌릴 땐 `python -u ... > run.log 2>&1` + `run_in_background`로 띄우고 `DONE`/`FAILED` 폴링할 것(로컬 직접 실행은 그냥 돌리면 됨). `pageUnit`을 더 키워도 서버가 50으로 잘라서 페이지 수는 안 줄어듦.
- **API 미사용:** 국립국어원 오픈API는 키가 필요해서 안 씀. 키 없이 공개 검색 페이지만 긁음.
